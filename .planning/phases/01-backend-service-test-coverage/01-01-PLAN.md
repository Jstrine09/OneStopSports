<objective>
Add the test seams (package-private test constructors) that the four currently-untestable external-API services need before their unit tests can compile, mirroring the existing NbaApiService test-constructor convention. Also widen BallDontLieService's response records so a same-package test can build fixture objects.

This is a production-code prerequisite plan: it changes only production source, adds NO behavior, and adds NO new tests. It exists so the Wave 2 adapter test plans (01-02, 01-03) can compile.

Purpose: Every one of these four services builds its own RestClient inside a @Value-driven constructor, so @InjectMocks cannot substitute a mock RestClient. NbaApiService already solved this with a package-private test constructor; this plan replicates that solution for the remaining four (per HARD-01, RESEARCH.md Pitfall 2, PATTERNS.md "Package-private test constructor").
Output: Four modified service files, each with a test constructor; BallDontLieService's two response records widened from private to package-private. Baseline 66 tests remain green.
</objective>
