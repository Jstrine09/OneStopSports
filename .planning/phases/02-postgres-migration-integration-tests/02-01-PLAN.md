<objective>
Stand up the Phase 2 build prerequisite and the real-Postgres integration-test skeleton. This plan adds the two Testcontainers test-scope dependencies plus an opt-in `integration` Maven profile to `pom.xml` (D-01, D-02), then creates `PostgresMigrationIT.java` — a plain-JUnit5 (no `@SpringBootTest`) Testcontainers test that runs the real V1→V9 Flyway chain in two stages against an ephemeral `postgres:16-alpine` (D-03) and asserts the V8 outcomes and the V9 *schema-shape* outcomes.

The exhaustive V9 *data-merge* assertions (duplicate-club merge, players/links/favourites re-pointing + collision-skip) and their duplicate-club fixtures are deliberately deferred to plan 02-02, which extends the SAME IT class and `seedFixtures` method this plan creates. This plan therefore delivers roadmap Success Criteria 1, 2, and 4, plus the schema-shape half of Criterion 3.

Purpose: These two migrations only ever run against real Postgres (Flyway is OFF in the H2 test profile — CLAUDE.md), so they are currently unverified by any test. This is the deliberate exception to the "mock all providers" rule: the database is real by design (D-01).
Output: `pom.xml` (2 deps + `integration` profile) and a new `PostgresMigrationIT.java` with a two-stage migrate `@BeforeAll` + V8/V9-schema `@Test` methods. The default `mvn test` H2 suite (120 tests) stays green and Docker-free.
</objective>
