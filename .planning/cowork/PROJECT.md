# OneStopSports — Project description

> Paste this into the **Project description** field of the Claude Cowork project.

---

**OneStopSports** is a Fotmob-style multi-sport web app covering football (soccer), the NBA, and the NFL. It surfaces live scores, league standings, match timelines, lineups, full team rosters, player profiles with career stats and headshots, and lets authenticated users save favourite teams and players. Live scores are pushed to the browser over WebSocket (STOMP) so the home screen updates instantly when a goal is scored.

**Stack:** Java 21 + Spring Boot 3.4.4 backend (PostgreSQL via Flyway-managed schema, Redis cache, JWT auth, Hibernate/JPA, MapStruct, Lombok) talking to five external sports APIs (football-data.org, ESPN unofficial NBA, ESPN unofficial NFL, balldontlie.io, api-sports.io football). React 18 + TypeScript + Vite frontend with Tailwind, React Query, axios, `@stomp/stompjs`. Docker Compose for full local boot.

**Current state:** Working end-to-end personal project, **publicly deployed**. All seven entities + all 5 external APIs are wired; live-score WebSocket push, JWT auth (short-lived access token + httpOnly rotating refresh cookie with DB-backed revocation), player career stats (3 sports) + bio + headshots (ESPN CDN for NBA/NFL, API-SPORTS media CDN for football), live game clock, match box score + event timeline, and a structural team↔league many-to-many model (a club is one row, belongs to many competitions) all work. The frontend went through a full "sport-field" redesign (animated pitch/court/gridiron backdrops + glass surfaces, shared `SectionLabel`/`RowCard` primitives, light/dark, responsive) and is now an installable PWA. Production deploy is **Vercel (frontend) + Render (backend) + Neon (Postgres)**, with CORS/WS origins locked down to the real deploy domains. Free-tier cold starts are mitigated by an external UptimeRobot monitor (5-min HTTP ping on `/api/sports`); the in-repo GitHub Actions keep-alive workflow was removed (GitHub throttled it too infrequently and its 90s curl timed out on cold starts). A 5-persona QA pass fixed all identified issues (auth bypass, 500→4xx, accessibility, stale-data badge, NBA conference standings, accent-insensitive search, duplicate clubs/players, PCT/GB columns, league logos/crests), followed by five further hardening fixes: unmapped routes → 404, Swagger disabled in prod (S2), football headshots + fallback tile (U1), auth rate limiting (S1), and the token-security overhaul above (S3). 148 backend tests pass (across 20 classes via `mvn test`, up from 66/9 as of Phase 1, 2026-07-08), plus 13 opt-in `PostgresMigrationIT` tests proving the V8/V9 Flyway migrations against real Postgres (Phase 2, 2026-07-13, `mvn verify -Pintegration`) — both phases of the `.planning/` "v1 Harden & Test" milestone are complete, current work is Phase 3 (frontend test foundation, not yet started). Known incomplete (free-tier limits): football stats are single-season capped at 2024, football match stats/lineups stubbed.

The codebase is treated as a teaching project — every Java file carries plain-English inline comments aimed at a junior developer (see CONVENTIONS.md). When working on this project, preserve that style.
